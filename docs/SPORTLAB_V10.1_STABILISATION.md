# SportLab V10.1 — Stabilisation API

Cette version corrige le chargement DrawHunter en ajoutant la saison football requise par API-Sports.
Les diagnostics distinguent désormais :
- OK : rencontres chargées ;
- EMPTY : aucune rencontre dans la fenêtre de sept jours ;
- ERROR : erreur API réelle avec code et détail.

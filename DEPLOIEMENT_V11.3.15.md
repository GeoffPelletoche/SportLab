# Déploiement SportLab V11.3.15

1. Remplacer le contenu du dépôt GitHub Pages par le contenu complet de cette archive.
2. Ne modifier ni la base D1 `sportlab-db`, ni les Workers Cloud Sync / API Bridge.
3. Après déploiement, ouvrir SportLab sur PC puis sur iPhone.
4. Vérifier que le Cloud reste connecté.
5. À l'accueil, l'état « Chargement des rencontres » peut apparaître brièvement ; dès réception des données sportives, la vue se met à jour automatiquement.
6. Tester le bouton « Actualiser » : il doit recharger Football/Rugby sans revenir à l'accueil et sans relancer la connexion Cloud.
7. Tester Accueil → DrawHunter → Accueil → FrenchFlair → Cloud : la navigation doit rester rapide.

Aucune migration D1 n'est requise.

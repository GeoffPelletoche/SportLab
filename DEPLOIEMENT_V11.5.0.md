# SportLab V11.5.0 — Portfolio Dashboard

## Déploiement
Remplacer le contenu du dépôt par cette archive complète puis laisser GitHub Pages se redéployer.

## Nouveautés
- Dashboard Portfolio Premium.
- Profit cumulé filtrable sur 7j / 30j / 3m / 1an / Tout.
- Paris, Profit net, ROI réel, Progression.
- Capital initial configurable (100 € par défaut), sauvegardé dans `sportlab.v7.settings`.
- Les statistiques détaillées historiques restent disponibles.

## Formules
- ROI réel = profit net / mises réglées × 100.
- Progression = profit net / capital initial × 100.
- Capital actuel = capital initial + profit net.

Aucun changement Cloudflare requis.
